# Wallet
1. `flutter create . --project-name wallet` (generates android/ios/desktop folders; keeps lib/ and pubspec.yaml)
2. `flutter pub get && flutter run`

Daily notes: file named `YYYY-MM-DD.md`, payment lines like `- 45000 Lunch #food`.
Tap the folder icon to point at your Obsidian vault; without it, demo data is shown.
